### Description: 
CookAssist is a terminal application that allows users to organize and manage recipes and easily find recipes based on available ingredients and cooking time. Users can maintain a list of ingredients they have available and generate a shopping list for any recipe containing ingredients they are missing.\

### Intended Users:
Anyone wanting to keep a cooking log/recipe log
Students who need a go-to place for recipes and shopping lists on the go
Home cooks looking to organize their recipe collection
Essential vs Optional Features

### Essential Features:
- Add and manage recipes - Users can create recipes with a name, description, cooking time, and list of ingredients
- Browse and filter recipes - Users can search and filter recipes based on ingredients and maximum cooking time
- Built-in recipes - The application will provide several simple recipes that users can browse and use immediately
- Generate shopping lists - Users can select a recipe and generate a shopping list containing ingredients they do not currently have available

### Optional Features:
- Cooking timer - Users can start a timer in the app when they begin cooking a recipe, set by each recipe's cook time
- Ingredient-based recipe suggestions - The application can suggest recipes that can be made using the ingredients the user currently has available
